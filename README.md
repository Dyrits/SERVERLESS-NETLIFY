# SERVERLESS-NETLIFY

Serverless functions running on Netlify.

## About The Project

A Netlify Functions project using axios for HTTP requests, nodemailer for sending email, Stripe for payments and dotenv for environment configuration.

### Built With

- Node.js
- Netlify Functions
- Stripe, Nodemailer, Axios

## Getting Started

### Prerequisites

- Node.js
- Netlify CLI

### Installation

```sh
npm install
npm run netlify    # netlify dev
```
